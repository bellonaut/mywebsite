# bashir.bio

Personal site + portfolio for **Bashir Aminu Bello** — Nigerian-born health data scientist building privacy-safe, low-bandwidth tools for African health systems.
And cool Overwatch gamer, Last Cloudia Enjoyer, avid walker through nature, and chief of the "smile-first" syndicate.
*fortune favors the bold*

**Live:** https://bashir.bio

## What’s inside 
- Portfolio projects (NaijaCare, health metrics work, applied ML)
- Writing feed (Substack)
- Contact + booking links
- Interactive “Where I’ve been” globe

## Tech
- Astro
- TypeScript
- Vercel
- UnoCSS

## Local dev
```bash
pnpm install
pnpm dev
```

## Visit notifications
- Set `RESEND_API_KEY` plus optional `RESEND_FROM`, `NOTIFY_EMAIL`, and `NOTIFY_EXCLUDE_IPS` (comma-separated) in your deployment environment.
- To suppress notifications for your own browser, visit `https://bashir.bio/?notify=off` once (use `?notify=on` to re-enable).
